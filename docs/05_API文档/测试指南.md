## 1. 测试概述

### 测试策略

Story Wiki 采用以下测试策略：

1. **单元测试**：测试单个函数和方法
2. **集成测试**：测试模块之间的交互
3. **功能测试**：测试完整功能流程
4. **性能测试**：测试关键路径的性能

### 测试框架

- **pytest**：主要测试框架
- **pytest-cov**：覆盖率报告
- **pytest-mock**：模拟对象
- **pytest-asyncio**：异步测试支持

### 测试目录结构

```
tests/
├── __pycache__/              # 缓存目录
├── test_chapter_generator.py # 章节生成器测试
├── test_create.py            # 创作管线测试
├── test_dedup_optimization.py # 去重优化测试
├── test_incremental.py       # 增量分析测试
├── test_novel_logger.py      # 小说日志测试
├── test_plot_generator.py    # 情节生成器测试
└── test_vault_manager.py     # 知识库管理测试
```

## 2. 测试环境配置

### 安装依赖

```bash

pip install pytest pytest-cov pytest-mock pytest-asyncio

# 或者使用requirements文件
pip install -r requirements-test.txt
```

### 环境变量

测试需要以下环境变量：

```bash
# .env.test
DEEPSEEK_API_KEY=your_test_api_key
VAULT_DIR=./test_vault
```

### 测试配置

创建 `pytest.ini` 或 `pyproject.toml`：

```ini
# pytest.ini
[pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
addopts = -v --tb=short
markers =
    slow: marks tests as slow (deselect with '-m "not slow"')
    integration: marks tests as integration tests
```

## 3. 运行测试

### 运行所有测试

```bash
# 运行所有测试
pytest

# 运行所有测试并显示详细输出
pytest -v

# 运行所有测试并生成覆盖率报告
pytest --cov=src --cov-report=html
```

### 运行特定测试

```bash
# 运行特定文件
pytest tests/test_vault_manager.py

# 运行特定类
pytest tests/test_vault_manager.py::TestVaultManager

# 运行特定方法
pytest tests/test_vault_manager.py::TestVaultManager::test_load_character

# 运行匹配特定模式的测试
pytest -k "character"
```

### 运行特定标记的测试

```bash
# 运行非慢速测试
pytest -m "not slow"

# 运行集成测试
pytest -m "integration"
```

### 测试选项

```bash
# 显示详细输出
pytest -v

# 显示打印输出
pytest -s

# 遇到第一个失败后停止
pytest -x

# 显示最慢的10个测试
pytest --durations=10

# 并行运行测试（需要pytest-xdist）
pytest -n auto
```

## 5. 编写新测试

### 测试文件命名规范

- 测试文件以 `test_` 开头
- 测试类以 `Test` 开头
- 测试方法以 `test_` 开头

### 测试结构模板

```python
import pytest
from src.module import FunctionToTest

class TestFunctionToTest:
    """测试 FunctionToTest 函数"""
    
    def setup_method(self):
        """每个测试方法前执行"""
        self.test_data = "test_value"
    
    def teardown_method(self):
        """每个测试方法后执行"""
        pass
    
    def test_function_normal_case(self):
        """测试正常情况"""
        result = FunctionToTest(self.test_data)
        assert result == expected_value
    
    def test_function_edge_case(self):
        """测试边界情况"""
        result = FunctionToTest("")
        assert result is None
    
    def test_function_error_case(self):
        """测试错误情况"""
        with pytest.raises(ValueError):
            FunctionToTest(None)
```

### 使用fixtures

```python
@pytest.fixture
def sample_character():
    """创建测试用人物数据"""
    return {
        "name": "测试人物",
        "identity": "主角",
        "personality": "勇敢",
        "gender": "男"
    }

@pytest.fixture
def vault_manager():
    """创建测试用VaultManager"""
    config = {"vault_dir": "./test_vault"}
    return VaultManager(config)

def test_with_fixture(vault_manager, sample_character):
    """使用fixture的测试"""
    vault_manager.add_character(sample_character)
    character = vault_manager.load_character("测试人物")
    assert character.name == "测试人物"
```

### 使用模拟对象

```python
from unittest.mock import Mock, patch

def test_with_mock():

```

## 6. 测试覆盖率

### 生成覆盖率报告

```bash
# 生成HTML覆盖率报告
pytest --cov=src --cov-report=html

# 生成终端覆盖率报告
pytest --cov=src --cov-report=term-missing

# 覆盖率阈值检查
pytest --cov=src --cov-fail-under=80
```

### 覆盖率目标

- **总体覆盖率**：≥ 80%
- **核心模块**：≥ 90%（analyzer.py, pipeline.py, generator.py）
- **工具模块**：≥ 70%（utils.py, config.py）

### 覆盖率报告解读

- **行覆盖率**：执行的代码行比例
- **分支覆盖率**：执行的分支比例
- **函数覆盖率**：调用的函数比例

## 7. 持续集成

### GitHub Actions配置

```yaml
# .github/workflows/test.yml
name: Test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: [3.13]
    
    steps:
    - uses: actions/checkout@v3
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: ${{ matrix.python-version }}
    
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
        pip install -r requirements-test.txt
    
    - name: Run tests
      run: |
        pytest --cov=src --cov-report=xml
    
    - name: Upload coverage to Codecov
      uses: codecov/codecov-action@v3
      with:
        file: ./coverage.xml
```

### 本地CI脚本

```bash
#!/bin/bash

echo "Checking coverage..."
pytest --cov=src --cov-fail-under=80
```

## 8. 测试最佳实践

### 1. 测试独立性
- 每个测试应该独立运行
- 避免测试之间的依赖
- 使用fixtures管理测试数据

### 2. 测试可读性
- 测试名称清晰表达测试意图
- 使用描述性的断言消息
- 保持测试简单明了

### 3. 测试速度
- 避免不必要的IO操作
- 使用模拟对象替代外部依赖
- 标记慢速测试

### 4. 测试维护
- 定期重构测试代码
- 删除过时的测试
- 保持测试与代码同步更新

## 9. 常见问题

### Q: 测试运行失败怎么办？

**检查步骤：**
1. 确保所有依赖已安装
2. 检查环境变量配置
3. 查看详细错误信息：`pytest -v`
4. 运行单个测试定位问题：`pytest tests/test_file.py::test_function -v`

### Q: 如何调试测试？

**调试方法：**
1. 使用 `pytest -s` 显示打印输出
2. 使用 `pytest --pdb` 进入调试器
3. 在测试中添加 `breakpoint()`
4. 使用IDE的调试功能

### Q: 测试覆盖率不足怎么办？

**提升覆盖率：**
1. 分析未覆盖的代码：`pytest --cov-report=html`
2. 为未覆盖的分支添加测试
3. 测试边界条件和错误情况
4. 使用参数化测试覆盖多种输入

### Q: 如何处理外部API依赖？

**处理方法：**
1. 使用模拟对象替代API调用
2. 使用VCR录制HTTP交互
3. 创建测试替身（Test Doubles）
4. 使用环境变量控制测试模式
