## 1. 部署概述

### 部署选项

Story Wiki 支持以下部署方式：

1. **本地部署**：在个人电脑上运行
2. **服务器部署**：在Linux/VPS服务器上运行
3. **Docker部署**：使用容器化部署
4. **云服务部署**：部署到AWS/阿里云等云平台

### 架构说明

```
┌─────────────────────────────────────┐
│         Story Wiki 系统            │
├─────────────────────────────────────┤
│  用户接口层                         │
│  ├── main.py (CLI)                 │
│  ├── agent.py (交互式)             │
│  └── create.py (创作管线)          │
├─────────────────────────────────────┤
│  业务逻辑层                         │
│  ├── analyzer.py (AI分析)          │
│  ├── pipeline.py (分析管线)        │
│  ├── generator.py (笔记生成)       │
│  └── chapter_generator.py (章节)   │
├─────────────────────────────────────┤
│  数据存储层                         │
│  ├── extractor.py (文本提取)       │
│  ├── splitter.py (章节切分)        │
│  └── Obsidian Vault (Markdown)     │
└─────────────────────────────────────┘
```

## 2. 环境要求

### 硬件要求

**最低配置：**
- CPU：2核
- 内存：4GB
- 存储：20GB（根据数据量调整）
- 网络：需要访问DeepSeek API

**推荐配置：**
- CPU：4核
- 内存：8GB
- 存储：50GB SSD
- 网络：稳定高速连接

### 软件要求

**操作系统：**
- Windows 10/11
- Linux (Ubuntu 20.04+, CentOS 7+)
- macOS 10.15+

**Python环境：**
- Python 3.13 或更高版本
- pip 21.0 或更高版本

**依赖服务：**
- DeepSeek API 访问权限
- Obsidian（用于查看生成结果）

## 3. 本地部署

### 3.1 获取代码

```bash
# 克隆项目
git clone https://github.com/your-username/story_wiki.git
cd story_wiki

# 或者直接下载压缩包
wget https://github.com/your-username/story_wiki/archive/main.zip
unzip main.zip
cd story_wiki-main
```

### 3.2 环境配置

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 安装可选依赖（epub/pdf支持）
pip install -r requirements-optional.txt
```

### 3.3 配置API密钥

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑.env文件，填入API密钥
DEEPSEEK_API_KEY=your_api_key_here
```

### 3.4 验证安装

```bash
# 运行测试
python -m pytest tests/ -v

# 测试导入
python -c "from src.analyzer import analyze_text; print('Import successful')"

# 显示帮助
python -m src.main --help
```

### 3.5 运行程序

```bash
# 交互模式
python -m src.main --interactive

# 分析文本
python -m src.main --input story.txt --output ./output_vault

# 创作小说
python -m src.main --create --input story.txt --output ./novel_vault
```

## 4. 服务器部署

### 4.1 系统准备

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装必要软件
sudo apt install -y python3.13 python3.13-venv python3-pip git

# 创建部署用户
sudo useradd -m -s /bin/bash storywiki
sudo su - storywiki
```

### 4.2 项目部署

```bash
# 克隆项目
git clone https://github.com/your-username/story_wiki.git
cd story_wiki

# 创建虚拟环境
python3.13 -m venv venv
source venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
nano .env  # 编辑配置
```

### 4.3 设置系统服务

创建systemd服务文件：

```bash
sudo nano /etc/systemd/system/storywiki.service
```

服务文件内容：

```ini
[Unit]
Description=Story Wiki AI Agent
After=network.target

[Service]
Type=simple
User=storywiki
Group=storywiki
WorkingDirectory=/home/storywiki/story_wiki
Environment=PATH=/home/storywiki/story_wiki/venv/bin
ExecStart=/home/storywiki/story_wiki/venv/bin/python -m src.main --interactive
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用并启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable storywiki
sudo systemctl start storywiki
sudo systemctl status storywiki
```

### 4.4 配置防火墙

```bash
# 如果需要远程访问
sudo ufw allow ssh
sudo ufw enable
```

### 4.5 日志管理

```bash
# 查看服务日志
sudo journalctl -u storywiki -f

# 配置日志轮转
sudo nano /etc/logrotate.d/storywiki
```

日志轮转配置：

```
/home/storywiki/story_wiki/logs/*.log {
    daily
    missingok
    rotate 14
    compress
    delaycompress
    notifempty
    create 0644 storywiki storywiki
}
```

## 5. Docker部署

### 5.1 创建Dockerfile

```dockerfile
# Dockerfile
FROM python:3.13-slim

# 设置工作目录
WORKDIR /app

# 复制依赖文件
COPY requirements.txt .

# 安装依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制项目文件
COPY . .

# 设置环境变量
ENV PYTHONPATH=/app
ENV PYTHONUNBUFFERED=1

# 暴露端口（如果需要Web界面）
EXPOSE 8000

# 启动命令
CMD ["python", "-m", "src.main", "--interactive"]
```

### 5.2 构建镜像

```bash
# 构建Docker镜像
docker build -t story-wiki:latest .

# 查看镜像
docker images | grep story-wiki
```

### 5.3 运行容器

```bash
# 运行容器
docker run -d \
  --name story-wiki \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/output:/app/output \
  -e DEEPSEEK_API_KEY=your_api_key \
  story-wiki:latest

# 查看日志
docker logs -f story-wiki

# 进入容器
docker exec -it story-wiki bash
```

### 5.4 Docker Compose

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  story-wiki:
    build: .
    container_name: story-wiki
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
      - ./output:/app/output
      - ./logs:/app/logs
    environment:
      - DEEPSEEK_API_KEY=${DEEPSEEK_API_KEY}
      - VAULT_DIR=/app/output
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "python", "-c", "import sys; sys.exit(0)"]
      interval: 30s
      timeout: 10s
      retries: 3
```

运行Docker Compose：

```bash
# 启动服务
docker-compose up -d

# 查看状态
docker-compose ps

# 停止服务
docker-compose down
```

**日志文件：**
```

├── story_wiki.log          # 主日志
├── story_wiki_error.log    # 错误日志
└── story_wiki_access.log   # 访问日志
```

### 7.3 健康检查

创建健康检查脚本：

```python
#!/usr/bin/env python3
# scripts/health_check.py

import sys
import requests
from src.config import load_config

def check_health():
    """检查系统健康状态"""
    config = load_config()
    
    # 检查API连接
    try:
        response = requests.get("https://api.deepseek.com/health", timeout=5)
        if response.status_code != 200:
            print("ERROR: API连接失败")
            return False
    except Exception as e:
        print(f"ERROR: API连接异常 - {e}")
        return False
    
    # 检查磁盘空间
    import shutil
    usage = shutil.disk_usage("/")
    if usage.free < 1024**3:  # 小于1GB
        print("WARNING: 磁盘空间不足")
    
    print("系统健康检查通过")
    return True

if __name__ == "__main__":
    sys.exit(0 if check_health() else 1)
```

## 8. 备份与恢复

### 8.1 备份策略

**备份内容：**
- 配置文件（.env）
- 知识库数据（output_vault/）
- 日志文件（logs/）
- 创作的小说（novels/）

**备份频率：**
- 每日增量备份
- 每周完整备份
- 重要操作前备份

### 8.2 备份脚本

```bash
#!/bin/bash
# scripts/backup.sh

BACKUP_DIR="./backups"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/story_wiki_$DATE.tar.gz"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 创建备份
tar -czf $BACKUP_FILE \
  .env \
  output_vault/ \
  logs/ \
  novels/ \
  data/

# 删除30天前的备份
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete

echo "备份完成: $BACKUP_FILE"
```

### 8.3 恢复流程

```bash
#!/bin/bash
# scripts/restore.sh

BACKUP_FILE=$1

if [ -z "$BACKUP_FILE" ]; then
    echo "用法: $0 <backup_file>"
    exit 1
fi

# 恢复备份
tar -xzf $BACKUP_FILE

# 重新安装依赖
source venv/bin/activate
pip install -r requirements.txt

echo "恢复完成"
```

### 8.4 数据迁移

```bash
# 迁移到新服务器
# 1. 在旧服务器备份
./scripts/backup.sh

# 2. 传输备份文件
scp backups/story_wiki_*.tar.gz user@new-server:/path/to/story_wiki/

# 3. 在新服务器恢复
./scripts/restore.sh story_wiki_*.tar.gz
```

## 9. 安全建议

### 9.1 API密钥安全

- 不要将API密钥提交到版本控制
- 使用环境变量或密钥管理服务
- 定期轮换API密钥
- 限制API密钥的权限

### 9.2 系统安全

- 定期更新系统和依赖
- 使用防火墙限制访问
- 监控系统日志
- 定期进行安全审计

### 9.3 数据安全

- 定期备份数据
- 加密敏感数据
- 实施访问控制
- 监控数据访问

## 10. 故障排除

### 常见问题

**Q: 服务无法启动**
```bash
# 检查日志
sudo journalctl -u storywiki -f

# 检查端口占用
netstat -tulpn | grep :8000

# 检查权限
ls -la /home/storywiki/story_wiki
```

**Q: API调用失败**
```bash
# 检查API密钥
echo $DEEPSEEK_API_KEY

# 测试API连接
curl -H "Authorization: Bearer $DEEPSEEK_API_KEY" https://api.deepseek.com/v1/models
```

**Q: 磁盘空间不足**
```bash
# 检查磁盘使用
df -h

# 清理旧文件
find . -name "*.log" -mtime +30 -delete
```
