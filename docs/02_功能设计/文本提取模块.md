# 文本提取模块

## 职责

将各种格式的输入文件转换为纯文本字符串。

## 接口

```python
def extract_text(file_path: str) -> str:
    """读取文件，返回纯文本内容。"""
```

## 支持格式

| 格式 | 方案 | Demo 阶段 |
|------|------|-----------|
| .txt | 直接读取 | ✅ 必须 |
| .epub | ebooklib | ❌ 后续 |
| .pdf | pymupdf | ❌ 后续 |

## 处理流程

1. 检测文件扩展名
2. 按格式选择读取方式
3. 基础清理（去除多余空行、特殊字符）
4. 返回纯文本字符串

## 错误处理

- 文件不存在 → 抛出 FileNotFoundError
- 编码问题 → 尝试 utf-8 → gbk → gb2312
- 格式不支持 → 抛出 ValueError
