# 笔记生成模块

## 职责

将 AI 分析的 JSON 数据转换为 Obsidian Markdown 文件，写入 vault。

## 接口

```python
def generate_vault(analysis: dict, output_dir: str) -> list[str]:
    """
    输入分析结果 JSON，输出目录路径。
    返回生成的文件路径列表。
    """
```

## 生成内容

### 1. 人物卡片 → `characters/{人名}.md`

```markdown
---
type: character
source: analyzed
origin: {作品名}
tags: [character, {势力}]
aliases: [{别名列表}]
---

# {人名}

## 身份
{身份描述}

## 性格
{性格描述}

## 人际关系
- [[{关系人}]] — {关系类型}
```

### 2. 设定卡片 → `settings/{设定名}.md`

```markdown
---
type: setting
source: analyzed
origin: {作品名}
tags: [setting]
---

# {设定名}

{描述}
```

### 3. 作品索引 → `_index.md`

```markdown
# {作品名}

> {一句话摘要}

## 人物
- [[{人名}]] — {身份}

## 设定
- [[{设定名}]] — {简述}
```

## 目录结构

每次分析一个作品，在 vault 下创建对应文件夹：

```
vault/
├── .obsidian/
├── {作品名}/
│   ├── _index.md
│   ├── characters/
│   │   ├── 人物A.md
│   │   └── 人物B.md
│   └── settings/
│       └── 设定A.md
```

## Wikilink 规范

- 人物间关系：`[[人名]]`，Obsidian 自动识别为边
- 不使用命名空间前缀（如 `[[人物:贾宝玉]]`），保持简洁
- 同名人物（跨作品）通过文件夹隔离，不冲突
