# 开发流程

## Phase 1 开发顺序

```
Step 1: Vault 骨架搭建
  → 创建目录结构、.obsidian 配置、模板文件
  → 验证：Obsidian 能打开 vault

Step 2: 文本读取模块 (extractor.py)
  → 实现 extract_text(file_path) -> str
  → 验证：能正确读取 txt 文件

Step 3: AI 分析模块 (analyzer.py)
  → 实现 prompt 设计 + DeepSeek API 调用 + JSON 解析
  → 验证：输入文本返回合法 JSON

Step 4: 笔记生成模块 (generator.py)
  → 实现 generate_vault(analysis, output_dir)
  → 验证：生成的 .md 文件格式正确

Step 5: 端到端测试
  → 准备一段测试文本（红楼梦片段或任意有角色的文字）
  → 跑完整流程
  → 用 Obsidian 打开验证 Graph View
```

## 测试方法

### 单模块测试

```bash
# 测试 extractor
python -c "from src.extractor import extract_text; print(extract_text('data/input/test.txt')[:200])"

# 测试 analyzer
python -c "from src.analyzer import analyze_text; import json; print(json.dumps(analyze_text('测试文本'), ensure_ascii=False, indent=2))"
```

### 端到端测试

```bash
python src/analyzer.py --input data/input/test.txt --output vault/
```

然后用 Obsidian 打开 `vault/` 目录检查。

## 调试技巧

1. **AI 返回异常**：检查 `data/state/` 下的原始响应
2. **Graph View 不显示**：检查 wikilink 格式是否正确（`[[人名]]` 不是 `[人名]()`
3. **人物卡片空白**：检查 JSON 字段名是否匹配

## Git 约定

- vault/ 目录加 .gitignore（自动生成的不需要版本控制）
- data/input/ 下的测试文本可以提交
- commit message：`模块名: 做了什么`
