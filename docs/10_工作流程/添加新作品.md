# 添加新作品流程

## 操作步骤

1. 将文本文件放入 `data/input/` 目录
2. 运行分析脚本
3. 检查 vault 下生成的文件
4. 用 Obsidian 打开验证

## 命令

```bash
# 分析新作品
python src/analyzer.py --input data/input/新作品.txt --output vault/

# 指定作品名（不从文件名推断）
python src/analyzer.py --input data/input/book.txt --title "作品名" --output vault/
```

## 分析后检查清单

- [ ] vault/{作品名}/ 目录已创建
- [ ] _index.md 内容完整
- [ ] characters/ 下有人物卡片
- [ ] 人物卡片中 wikilink 格式正确
- [ ] settings/ 下有设定卡片（如有）
- [ ] Obsidian Graph View 能看到关系连线
