# 数据模型

## 核心实体

### 1. 人物（Character）

```yaml
---
type: character
source: analyzed | generated
origin: 作品名
tags: [character, 势力名]
aliases: [别名1, 别名2]
---

# 人物名

## 身份
一句话描述身份背景

## 性格
关键性格特征

## 人际关系
- [[人物B]] — 关系类型
- [[人物C]] — 关系类型
```

### 2. 设定（Setting）

```yaml
---
type: setting
source: analyzed | generated
origin: 作品名
tags: [setting, 地点|组织|体系]
---

# 设定名

描述内容
```

### 3. 事件（Event）

```yaml
---
type: event
source: analyzed | generated
origin: 作品名
time: 时间描述（如"1994年"）
chapter: 章节名
tags: [event]
---

# 事件名

**时间**：时间描述

一句话描述事件内容

## 参与人物
- [[人物A]]
- [[人物B]]

## 发生地点
- [[设定A]]

## 前置事件
- [[事件B]]
```

### 4. 关系（Relationship）

不单独建文件，直接写在人物卡的「人际关系」章节中，用 wikilink 连接。

Obsidian Graph View 自动将 `[[xxx]]` 识别为图的边。

## 关系类型词典

| 类型 | 说明 | 示例 |
|------|------|------|
| 恋人 | 爱情关系 | 宝玉↔黛玉 |
| 夫妻 | 婚姻关系 | 宝玉↔宝钗 |
| 父子/母子 | 亲子关系 | 贾政↔宝玉 |
| 师徒 | 教学关系 | 唐僧↔悟空 |
| 敌对 | 冲突关系 | 悟空↔妖怪 |
| 朋友 | 友谊关系 | 刘备↔关羽 |
| 主仆 | 上下级关系 | 贾母↔鸳鸯 |
| 同门 | 同组织关系 | 梁山好汉 |

## 文件命名规则

- 人物文件：`characters/{人名}.md`
- 设定文件：`settings/{设定名}.md`
- 事件文件：`events/{事件名}.md`
- 索引文件：`_index.md`
- 书籍元信息：`book.md`

## 关系图谱

`_index.md` 中嵌入 Mermaid 图谱，展示人物关系网络：
- 人物数 ≤ 30：展示所有人物关系
- 人物数 > 30：只展示主要人物（按关系数量 top 15）的关系

## 时间线

`_index.md` 中嵌入 Mermaid timeline，按章节分组展示事件：
- 事件按 chapter 字段分组
- 每个事件显示名称和参与人物
