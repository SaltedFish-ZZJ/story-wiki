# 数据模型

## 核心实体

### 1. 人物（Character）

```yaml
---
type: character
source: analyzed | generated
origin: 作品名
tags: [character, 势力名]
aliases: [别名1, 别名2]
---

# 人物名

## 身份
一句话描述身份背景

## 性格
关键性格特征

## 人际关系
- [[人物B]] — 关系类型
- [[人物C]] — 关系类型
```

### 2. 设定（Setting）

```yaml
---
type: setting
source: analyzed | generated
origin: 作品名
tags: [setting, 地点|组织|体系]
---

# 设定名

描述内容
```

### 3. 关系（Relationship）

不单独建文件，直接写在人物卡的「人际关系」章节中，用 wikilink 连接。

Obsidian Graph View 自动将 `[[xxx]]` 识别为图的边。

## 关系类型词典

| 类型 | 说明 | 示例 |
|------|------|------|
| 恋人 | 爱情关系 | 宝玉↔黛玉 |
| 夫妻 | 婚姻关系 | 宝玉↔宝钗 |
| 父子/母子 | 亲子关系 | 贾政↔宝玉 |
| 师徒 | 教学关系 | 唐僧↔悟空 |
| 敌对 | 冲突关系 | 悟空↔妖怪 |
| 朋友 | 友谊关系 | 刘备↔关羽 |
| 主仆 | 上下级关系 | 贾母↔鸳鸯 |
| 同门 | 同组织关系 | 梁山好汉 |

## 文件命名规则

- 人物文件：`characters/{人名}.md`
- 设定文件：`settings/{设定名}.md`
- 索引文件：`_index.md`
- 书籍元信息：`book.md`
